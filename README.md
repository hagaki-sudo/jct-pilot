# JCT PILOT

首都高の「次のJCTと進行方向」に表示を絞った、スマートフォン向けPWAの試作版です。

## 起動方法

位置情報とService Workerを使用するため、ファイルを直接開かずローカルHTTPサーバーから起動します。

Node.jsがある場合:

```powershell
npx --yes serve .
```

Pythonがある場合:

```powershell
python -m http.server 4173
```

表示されたURLをブラウザで開きます。PCでは「デモ走行」、スマートフォンでは「現在地で開始」を使用できます。

## 現在の機能

- 画像指定ルート「初台南 → 横浜・川崎 → C2 → 富ヶ谷」
- C1内回り・外回りの試験ルート
- GPSによる次JCTの推定
- 2km・800m・300m地点の音声案内
- 実機がなくても確認できる模擬走行
- オフラインキャッシュとホーム画面追加に対応するPWA構成

## 画像から登録したルート

1. 初台南入口からC2内回りへ
2. 富ヶ谷出口を通過（出口へ出ない）
3. 大井JCTから湾岸線・横浜方面へ
4. 東海JCTは湾岸線本線を継続
5. 本牧JCTからK3狩場線へ
6. 石川町JCTからK1横羽線・東京方面へ
7. 金港JCTはK1を継続
8. 大師JCTからK6川崎線へ
9. 川崎浮島JCTから湾岸線・東京／千葉方面へ
10. 葛西JCTからC2内回りへ
11. 堀切JCT、小菅JCT、江北JCT、板橋JCT、熊野町JCTでC2内回りを継続
12. 富ヶ谷出口（C22）で退出

各案内には、2026年7月1日時点の首都高ナビマップとJCT拡大図から読み取った緑看板の路線番号・地名を表示します。川崎浮島JCTは「首都高速 東京・横浜」から「B 東京」へ進む二段階案内です。

## 重要

収録座標・分岐方向・方面表示は、指定経路と首都高公式JCT図をもとに設定したプロトタイプ用データです。公道で使用する前に、公式資料と実走行を用いた全件検証が必要です。実際の道路標識、交通規制、通行止めを必ず優先してください。料金計算機能はありません。

## 本番化に必要な改善

- JCTではなく道路区間へのマップマッチング
- GPS履歴・進行方位・速度を使った上下線判定
- トンネル内の推測航法
- 全路線の有向グラフデータと検証済み案内文
- ルート編集、逸脱検出、復帰案内
- バックグラウンド位置情報とCarPlay / Android Auto対応
